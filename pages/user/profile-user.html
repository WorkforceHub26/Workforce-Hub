การแจ้งเตือนใบลานี้ผ่าน LINE (LINE Notification)

เมื่อเปิดใช้งานและผูก LINE User ID เรียบร้อยแล้ว ระบบจะส่งข้อความแจ้งเตือนสถานะใบลากลับมายังแอป LINE ของคุณทันทีเมื่อ:
  • ส่งคำขอลาใหม่สำเร็จ
  • หัวหน้างานหรือ HR พิจารณาอนุมัติใบลา
  • ใบลามีการปฏิเสธ หรือต้องการข้อมูลเพิ่มเติม

รับรหัสเชื่อมต่อและส่งไปที่ LINE OA เพื่อผูกบัญชีทันทีโดยไม่ต้องหา User ID เอง

ระบบล็อกอินด้วยลายนิ้วมือ / ใบหน้า (WebAuthn Biometrics)
